# 智能体工具知识库 P1

状态：已完成（第 7 轮验收通过）  
范围：Desktop OpenDrSai Agent 配置 V2  
目标：在“设置 → 智能体配置”中完成模型、工具、技能、知识库的一体化配置，并确保配置真实进入每次 Run 的运行时快照。

## 1. 背景与结论

当前项目已经具备 Agent 独立 TOML、模型策略、工具 CRUD、MCP、HepAI Worker、技能安装与热重载、SQLite 上下文和 RAGFlow 参数等基础能力，但它们分散在 Agent TOML、`TOOLS_CONFIG.json`、用户技能目录、环境变量和 Agent 创建硬编码中。

P1 不新建一套平行配置系统，而是采用“资源注册表 + Agent 引用 + Run 不可变快照”：

- 全局资源注册表定义工具、已安装技能和知识库连接。
- `configs/agents/agent_<agent_name>.toml` 定义某个 Agent 启用哪些资源。
- 每次 Run 保存最终解析结果，历史 Run 不被后续配置修改。
- 密钥只保存凭据引用，不写入 TOML、日志、Renderer 状态或 Run 快照。

## 2. 配置职责

```text
config.toml
├─ 当前 Agent 和 Agent 文件入口
├─模型 Provider 注册表
├─ Tool Registry 入口
└─ Knowledge Registry 入口

configs/
├─ agents/agent_<agent_name>.toml
├─ models/provider_<provider_id>.toml
├─ tools/tool_<tool_id>.toml
└─ knowledge/knowledge_<knowledge_id>.toml

skills/<skill_id>/SKILL.md
```

Agent 文件只保存资源 ID 和 Agent 级覆盖，不复制连接、密钥、技能正文或模型能力。

## 3. Agent 配置契约

Agent schema 升级到版本 2：

```toml
schema_version = 2
agent_name = "opendrsai"
display_name = "OpenDrSai"
description = "General-purpose local Agent"
enabled = true

[models]
reasoning_effort = "high"

[models.primary]
mode = "explicit"
provider_id = "provider-id"
model_id = "model-id"

[execution]
plan_mode = false
workspace_enabled = true

[tools]
mode = "explicit"
enabled = ["builtin.files", "builtin.shell", "web.search"]
disabled = []
require_approval = ["builtin.shell.write"]

[skills]
mode = "explicit"
enabled = ["document-review"]
disabled = []
allow_thread_override = true

[knowledge]
mode = "explicit"
sources = ["product-docs"]
retrieval_policy = "auto"
top_k = 6
score_threshold = 0.35
require_citations = true
```

资源选择模式统一为：

- `inherit`：继承系统或用户默认值。
- `explicit`：只启用 Agent 明确列出的资源。
- `all_enabled`：启用注册表中所有可用资源。

生产默认使用 `explicit`；旧配置迁移时使用 `inherit` 保持兼容。

## 4. 工具 P1

### 4.1 资源模型

每个工具必须具有稳定 `tool_id`，禁止继续以 JSON 数组下标作为身份。支持：

- 内建 FunctionTool；
- 本地 MCP stdio；
- 远程 MCP SSE/HTTP；
- HepAI Worker；
- Provider-native 工具的适配器。

工具状态统一为 `configured`、`available`、`degraded`、`credential_required`、`runtime_unavailable`、`unsupported_platform`、`disabled`。

### 4.2 运行时不变量

模型可见工具快照与执行注册表必须来自同一个 `ResolvedToolSet`。Agent 创建不得再自行硬编码另一套工具清单。

解析顺序：

```text
Agent policy → Tool Registry → 平台/凭据/连接检查
→ 实例化工具 → 模型工具快照 + 执行工具注册表 → Agent
```

### 4.3 API

```text
GET/POST                  /v1/config/tools
GET/PUT/DELETE            /v1/config/tools/{tool_id}
POST                      /v1/config/tools/{tool_id}/test
GET                       /v1/config/tools/{tool_id}/capabilities
GET/PUT                   /v1/config/agents/{agent_name}/tools
POST                      /v1/config/agents/{agent_name}/tools/preview
```

## 5. 技能 P1

严格区分“已安装”和“为 Agent 启用”。技能广场继续负责安装、更新、编辑和卸载；Agent 配置只维护绑定。

Run 有效技能：

```text
系统强制技能 + Agent 默认技能 + 线程临时技能 - Agent 禁用技能
```

当 `allow_thread_override=false` 时，不允许聊天输入框临时增加技能。技能缓存键必须至少包含 `user_id + agent_name + agent_revision + skills_revision`。

API：

```text
GET/PUT  /v1/config/agents/{agent_name}/skills
POST     /v1/config/agents/{agent_name}/skills/preview
POST     /v1/config/agents/{agent_name}/skills/reload
```

## 6. 知识库 P1

P1 支持两类资源：

- `local-files`：本地文件/目录，SQLite 索引；
- `ragflow`：远程 RAGFlow 数据集。

知识库与 Memory 分离：Memory 是偏好、会话摘要和项目经验；Knowledge Base 是显式数据源，可索引、检索、引用和重建。

知识库状态为 `not_indexed`、`indexing`、`ready`、`stale`、`failed`、`credential_required`。

API：

```text
GET/POST                  /v1/config/knowledge-bases
GET/PUT/DELETE            /v1/config/knowledge-bases/{knowledge_id}
POST                      /v1/config/knowledge-bases/{knowledge_id}/test
POST                      /v1/config/knowledge-bases/{knowledge_id}/index
GET                       /v1/config/knowledge-bases/{knowledge_id}/status
POST                      /v1/config/knowledge-bases/{knowledge_id}/search-preview
GET/PUT                   /v1/config/agents/{agent_name}/knowledge
POST                      /v1/config/agents/{agent_name}/knowledge/preview
```

检索证据必须包含 `knowledge_id`、文档 ID、标题或路径、chunk ID、score、来源和内容哈希，并进入 Run citation evidence。

## 7. Desktop 信息架构

“设置 → 智能体配置”中为具体 Agent 提供二级标签：

```text
模型 | 工具 | 技能 | 知识库 | 执行与上下文
```

- 工具：启用状态、来源、类型、Runtime 状态、权限摘要、测试和全局管理入口。
- 技能：已启用、已安装未启用、缺失/无效、技能广场入口。
- 知识库：绑定、类型、文档数、索引状态、最近索引时间和检索测试。
- 保存继续使用 revision 乐观锁；保存成功只使对应 Agent Runtime 缓存失效。
