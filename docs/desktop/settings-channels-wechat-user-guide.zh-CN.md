# Desktop 微信频道使用说明

## 支持范围

Desktop 当前通过微信 ilink Bot 接收和回复文字消息。支持：

- 二维码连接、重新连接和退出登录；
- 显式启用或停用频道；
- 每个微信用户独立会话；
- `/help`、`/newsession`、`/session`、`/session <id>`；
- 最终文字回复和超长文字自动分片；
- Desktop/Runtime 重启后恢复已经启用的频道。

暂不支持图片、语音、文件、视频、群管理和企业微信 Webhook。模型切换请在 Desktop 设置中完成，微信频道内的 `/model`、`/models` 不执行模型变更。

## 连接微信

1. 打开 `设置 > 频道`。
2. 找到“微信”卡片，点击“连接微信”。
3. 使用微信扫描 Desktop 内显示的二维码。
4. 在手机端确认。
5. Desktop 显示“已连接，未启用”后，点击“启用频道”。
6. 从微信向 Bot 发送一条文字消息，确认收到回复。

二维码只保存在当前窗口内存中；取消、过期、确认成功或关闭组件后会被清除。二维码过期后点击“刷新二维码”。

## 状态说明

| 状态 | 含义 | 建议操作 |
|---|---|---|
| 未连接 | 本机没有可用微信凭据 | 点击“连接微信”并扫码 |
| 已扫码，请在手机确认 | 微信已经识别二维码 | 在手机端完成确认 |
| 已连接，未启用 | 登录完成，但没有运行消息长轮询 | 点击“启用频道” |
| 运行中 | Runtime 正在接收微信消息 | 可直接从微信发送文字 |
| 登录已失效 | 凭据过期或系统安全存储不可用 | 点击“重新连接” |
| 重连/错误 | 网络或 Runtime 暂时不可用 | 检查网络，刷新状态或查看 Desktop 诊断 |

## 停用和退出登录

- “停用频道”仅停止接收新微信消息，保留登录凭据和历史会话。再次启用不需要扫码。
- “退出登录”会先停止频道，再删除系统安全存储中的微信凭据。历史会话默认保留；再次使用必须扫码。

## 会话和安全边界

- 不同微信用户映射到不同 Agent 会话，不能切换到其他用户的会话。
- 微信用户 ID 以散列键保存，Desktop UI、普通日志和诊断响应不显示原始 ID。
- 微信 token 保存在 Windows DPAPI 或 macOS Keychain 保护的凭据存储中，Renderer 不读取 token。
- 微信消息不会收到 Agent reasoning、工具参数或内部错误内容。
- 需要审批的高风险工具继续使用 Runtime 安全策略；没有可用批准决定时不会自动执行。

## 常见问题

### 二维码无法获取

确认 Desktop Runtime 已启动并且可以访问 `https://ilinkai.weixin.qq.com`。代理返回 403、TLS 拦截或网络超时会显示为无法联系微信。

### 已连接但消息没有回复

确认卡片状态是“运行中”，而不是“已连接，未启用”。随后查看 Desktop 诊断中的 Runtime 状态和微信错误码。

### 回复被拆成多条

微信单条文字限制为 2048 字符。Desktop Runtime 优先按换行分片，无法找到合适换行时按字符边界切分。

### 重启后没有自动恢复

只有此前处于“启用频道”状态时才会自动恢复。若登录已失效或系统凭据存储被清理，需要重新扫码。
