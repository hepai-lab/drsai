### 2. 🏗️ 优化架构

**目标：** 统一技能数据模型，模块化后端路由，支持多数据源同步。

#### 2.1 数据库模型统一（08/27 `71a5c895`）

将原来的双表结构（`SkillMeta` + `UserSkillMeta`）合并为一张统一的 `SkillMeta` 表，并新增 `SkillDetail` 表实现内容懒加载。

**SkillMeta 字段设计：**

| 分类 | 字段 | 说明 |
|------|------|------|
| 核心信息 | `slug`, `name`, `icon`, `version`, `profile`, `description` | 技能基础信息 |
| 归属与可见性 | `owner_id`, `author`, `visibility`, `source`, `source_ref`, `source_synced_at` | 所有者、来源、可见性控制 |
| 用户技能类型 | `uskills_type`, `imported_ref` | 区分 created/imported |
| 标签 | `tags`（JSON 数组） | 替代原有 `category` 字符串 |
| 统计 | `download_count` | 下载量（替代 `downloads`） |
| 关系 | `collector_ids`, `agent_ids`, `team_ids` | 收藏者、关联 Agent、团队 |

**SkillDetail 表：** 存放 `body`、`changelog`、`author_email`、`required_tools`、`detail_raw` 等重内容字段，实现列表查询与详情查询的解耦，提升列表页性能。

#### 2.2 后端路由模块化（08/27 `71a5c895`）

将原来的单文件 `skills_gfs.py`（2,251 行）拆分为模块化包：

```
skills_gfs/
├── __init__.py      # 路由注册
├── _auth.py         # 鉴权（113 行）
├── _delete.py       # 删除
├── _download.py     # 下载
├── _get.py          # 查询详情
├── _gfs.py          # GFS 云盘操作
├── _list.py         # 列表查询
├── _toggle.py       # 可见性切换
├── _update.py       # 更新
└── _upload.py       # 上传
```

#### 2.3 数据同步模块（新增）

新增 `skills_sync/` 包，支持从外部数据源同步技能：

```
skills_sync/
├── __init__.py
├── _base.py      # BaseSourceAdapter 抽象基类
├── _higraf.py    # HiGraf 适配器（从 higraf.ihep.ac.cn 拉取）
└── _sync.py      # 统一同步引擎（143 行）
```

**同步流程：**
1. 通过 HiGraf API 获取所有 skill 元数据（含 `callCount` 作为初始下载量）
2. 下载原始 ZIP 文件存入 GFS 的 `higraf/` 目录
3. 元数据写入 `SkillMeta` / `SkillDetail` 表（一次性 upsert，不覆盖已有数据）

**当前状态：** 35 个技能（HiGraf 同步 33 + 用户 yqsun@ihep.ac.cn 上传测试 2）

#### 2.4 远程技能代理（Remote Skill Proxy）

新增 `skill_grant.py` 和 `DrSaiAssistant` 中的远程技能下载能力，支持远端 Agent 通过 `/api/agent/skills/download` 接口拉取技能 ZIP：

- 基于 `X-User-Id` + `X-Skill-Proxy-Token` 鉴权
- 支持 `user_id` 身份识别，按 `slug` + `source` 精确下载
- 自动解析 `x-forwarded-host` / `x-forwarded-proto` 构建公开 URL

#### 2.5 API Key 鉴权重构（08/31 `3000255c`）

- 鉴权方式从 `?api_key=xxx` 查询参数统一迁移为 `Authorization: Bearer <api_key>` header
- 新增 `POST /logout` 端点，清除 refresh cookie
- 清理未使用的 import

**API 文档覆盖的接口：**

| 方法 | 端点 | 说明 |
|------|------|------|
| `GET` | `/api/skills` | 列出全部技能（支持 type/public/user、source、tags、q、sort、visibility、分页等参数） |
| `POST` | `/api/skills/upload` | 上传技能（multipart/form-data，支持 zip + profile 图片） |
| `PUT` | `/api/skills/{slug}` | 更新技能（所有字段可选，部分更新） |
| `GET` | `/api/skills/{slug}` | 获取技能详情（含 body、changelog、required_tools 等） |
| `DELETE` | `/api/skills/{slug}` | 删除技能（owner 或 admin） |
| `GET` | `/api/skills/{slug}/download` | 下载技能 ZIP |
| `PUT` | `/api/skills/{slug}/visibility` | 切换可见性 |
| `GET` | `/api/skills/{slug}/skill-md` | 获取 SKILL.md 内容 |

**文档包含：** 每个接口的 curl 示例、请求参数说明、响应 JSON 示例、错误码（200/400/401/403/404/413/422/500/502）。
