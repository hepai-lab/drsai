# OpenDrSai Android v1.4.6 Beta 真机验收清单

对应功能点：I07
安装包：`OpenDrSai-Android-v1.4.6.apk`
测试签名：Android Debug Certificate，仅用于内部 Beta

请至少使用两台不同品牌手机：一台 Android 10/11，一台 Android 13 或更高版本。每个项目填写“通过 / 失败 / 未测试”，失败时附系统版本、网络、操作步骤、截图或录屏。

## 1. 安装与登录

- [ ] 允许安装未知来源应用后能够正常安装或覆盖旧版。
- [ ] 桌面名称为 `OpenDrSai`，应用图标比例正常且使用 OpenDrSai Logo。
- [ ] 点击“使用 HepAI 继续”可打开系统浏览器或 Custom Tab。
- [ ] 登录授权完成后网页自动关闭并返回 OpenDrSai，不出现 `127.0.0.1`。
- [ ] 退出登录后回到登录页，再次登录仍可成功。

## 2. 聊天与键盘

- [ ] 标题栏和输入框为白色浮层，聊天内容在其下方可见。
- [ ] 输入法弹出后输入框贴近键盘，历史消息和起始内容同步上移。
- [ ] 纯文本消息能够发送、流式显示且没有 `null` 乱码或重复“正在思考”。

## 3. 三种附件入口

- [ ] 点击加号显示“拍照 / 从相册选择 / 选择文件”。
- [ ] 拍照仅请求必要的相机权限，拍照后出现缩略图草稿。
- [ ] 相册使用系统 Photo Picker，不要求广泛存储权限。
- [ ] 文件入口可选择 TXT、Markdown、CSV、JSON、XML、YAML、LOG 和 PDF。
- [ ] 不支持的格式、超过 10 MiB 的单文件、超过 5 个附件会显示明确提示。

## 4. 本机 OpenDrSai Runtime

- [ ] 文本附件：发送包含唯一标记的 TXT，回复能准确读出标记。
- [ ] PDF：发送测试 PDF，回复能概括其实际内容。
- [ ] 图片：发送包含可识别文字或物体的图片，回复能描述实际内容。
- [ ] 仅附件发送时能够处理，不需要额外输入文字。

## 5. HAI 平台 Agent

- [ ] Agent 列表可刷新并选择声明支持附件的 Agent。
- [ ] 文本附件上传、发送和处理成功。
- [ ] PDF 上传、发送和处理成功。
- [ ] 图片上传、发送和处理成功；不支持图片的 Agent 会提前提示而不是静默忽略。
- [ ] 上传进度可见，部分失败时文字和全部附件草稿仍然保留。

## 6. 中断、历史与结果文件

- [ ] 上传期间切换 Wi-Fi/移动网络，失败后可单独重试。
- [ ] 上传或聊天期间切后台再返回，页面不会崩溃或重复发送。
- [ ] 旋转屏幕或系统回收 Activity 后，未发送附件草稿可恢复。
- [ ] 历史消息重新打开后附件卡片仍存在，不依赖原始相册 URI。
- [ ] Agent 返回结果文件时可以下载、失败重试并用系统应用打开。
- [ ] 删除草稿、退出账号或附件过期后，缓存能按策略清理。

## 7. 稳定性记录

- [ ] 连续发送 10 轮含附件消息无崩溃、ANR 或明显持续内存增长。
- [ ] Wi-Fi 和移动网络各完成至少一轮附件上传与回复。
- [ ] 记录手机品牌/型号、Android 版本、OpenDrSai 版本、测试日期和测试结果。
