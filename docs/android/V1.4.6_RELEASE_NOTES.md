# OpenDrSai Android v1.4.6 Release Notes

状态：Beta 预发布说明；用于 I07 真机验收，正式版仍等待 I06、I07、J03 完成。
目标标签：`android-v1.4.6-beta.2`
目标资产：`OpenDrSai-Android-v1.4.6.apk`

## 主要更新

- 聊天输入栏新增“拍照、从相册选择、选择文件”三个附件入口。
- 支持 JPEG、PNG、WebP、TXT、Markdown、CSV、JSON、XML、YAML、LOG 和 PDF。
- 单次最多 5 个附件，单文件最大 10 MiB，单次总大小最大 25 MiB。
- 支持附件草稿、预处理、上传进度、取消、失败重试和仅附件发送。
- Android 本机 OpenDrSai Runtime 可读取文本、PDF 和图片附件。
- HAI 平台 Agent 使用 OIDC 所有权校验后的私有附件 ID，不传递 Android URI 或内部路径。
- 聊天历史可恢复附件卡片；Agent 结果文件支持下载、重试和系统应用打开。
- 新增受用户、thread 和 run 绑定的 DDF Artifact bridge；没有真实 producer 的 Agent 不发布 `artifact-output` 能力。
- Beta 2 修复本机 Runtime 把 DeepSeek 文本模型误判为视觉模型的问题：仅在模型明确支持视觉时发送 `image_url`，发送图片时自动切换到可用视觉模型；没有视觉模型时在上传前给出清晰提示。

## 发布门禁

Beta 资产可以先上传为 GitHub Pre-release，供真机验收下载；以下项目全部完成前不得转为正式 Release：

1. 平台管理员确认 ai-dev DDF 所连接的 `10.5.6.240/aidb` 是允许开发联调写入的隔离数据库，并确认新版 Artifact bridge 生效。
2. 在确认数据库隔离后，使用 ai-dev 真实 OIDC 会话完成图片、文本、PDF分别发送给本机 Runtime 与平台 Agent 的 6 组端到端测试。
3. 使用 Android 10/11 与 Android 13+ 两台不同品牌实体手机完成 I07 验收。
4. 将同一服务端版本部署至生产，并在 `https://ai.ihep.ac.cn` 完成 OIDC、Catalog、上传、Agent 处理和结果文件验证。
5. 正式版如继续使用测试签名，发布说明必须明确标注；重新构建时更新本文件中的 APK 大小和 SHA-256。
