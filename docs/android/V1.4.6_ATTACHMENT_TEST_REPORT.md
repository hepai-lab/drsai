## 尚未通过的发布门禁

1. ai-dev Backend 已于 2026-07-15 15:06:40 +08:00 重启并稳定在线；Catalog、Attachments、Native chat 未认证探测均为结构化 `401 invalid_token`。DDF 已于 15:10:02 恢复原 `42501` 监听并返回 `401`，但启动日志显示其实际连接 `10.5.6.240/aidb`，尚不能证明开发/生产数据隔离；在平台管理员确认该数据库用途前，不执行会写入 DDF 的真实会话测试。新增 Artifact bridge 的 HAI/DDF 开发代码已通过 98 项回归。
   - 联调中已修复 Android 对 `status/data/capabilities` envelope 的解析遗漏。
   - HAI catalog 已同时发布直接布尔能力键和兼容的 `features`，且仅对实际可执行 DDF/multimodal agent 开启。
2. F08 已完成：DDF 将受信 worker 的 `ddf.artifact` 内联事件规范化为带用户、thread、run 和 10 分钟 TTL 的一次性 opaque 引用；HAI 使用用户服务端 API Key 流式取回、执行 10 MiB/类型/魔数/大小/SHA-256/绑定校验，导入 Native 私有附件并消费内部引用，最终只向 Android 发送标准 `file_events`。当前没有真实智能体同时声明 `artifact-output=true` 与 `supported_events` 包含 `ddf.artifact`，因此目录能力保持关闭，避免虚假发布。
3. I07 需要两台实体手机覆盖 Android 10/11 与 Android 13+；先发布测试签名 Beta，由用户下载安装并按 `V1.4.6_BETA_DEVICE_CHECKLIST.md` 回传结果，模拟器结果不能替代该项。
4. Beta Pre-release 可先用于 I07；开发环境、真机与生产环境通过后，才将 J04 标记为正式发布完成。
