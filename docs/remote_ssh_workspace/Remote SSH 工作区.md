# Remote SSH 工作区

- **本质是远程执行环境**：Codex 桌面端通过 SSH 连接远程主机；选择 `/home/vscode` 并不是把目录下载或挂载到本地，而是将它设为远程工作区根目录。
- **操作在远程主机执行**：文件读写、Shell 命令、Git、构建和测试都由远程主机上的 Codex 执行端完成，本机主要负责交互和展示结果。
- **会话来自远程环境**：连接后，桌面端会加载该远程 Codex 环境维护的线程、项目、审批和运行状态，因此可以看到这台机器上的相关会话。
- **主机通常来自 SSH 配置**：Codex 可从本机 OpenSSH 配置中发现 `remote_3090` 等主机，并沿用其中的用户、密钥、端口和跳板机设置。
- **权限等同于 SSH 用户权限**：Codex 能访问的文件、凭据和系统资源受远程 SSH 用户权限控制，应使用最小权限用户，避免直接使用 `root`。
- **不要与 Remote Control 混淆**：Remote SSH 是桌面端进入远程开发机执行任务；Remote Control 是手机或另一客户端远程查看和操控正在运行 Codex 的主机。
