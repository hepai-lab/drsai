# OpenDrSai Android 主界面设计

状态：**第一版设计与实现已完成（2026-07-13）**。

## 设计目标

主界面只突出两件事：阅读对话和发送消息。历史、模型、账号与设置属于低频操作，统一收纳到左侧栏。
界面不使用固定的传统 AppBar 和分割线；标题控件与输入栏以圆角 Surface 浮在聊天内容之上。

## 页面结构

```text
┌───┐ ┌───────────┐       ┌───┐
│ ☰ │ │ OpenDrSai │       │ ＋│  独立浮动控件
└───┘ └───────────┘       └───┘

   Assistant 回答采用开放正文布局。

                   ┌─────────┐
                   │ 用户消息 │
                   └─────────┘

┌─────────────────────────────┐
│  ＋   给 OpenDrSai 发消息…  🎤 │  浮动输入栏
└─────────────────────────────┘
```

## 浮动标题栏

- 左侧只有侧栏展开按钮和 `OpenDrSai` 文字，左对齐；标题栏不显示 Logo；
- 右侧只有新会话按钮；
- 不使用横跨屏幕的标题栏底板；菜单、标题和新会话分别使用半透明的独立悬浮 Surface，其余区域透明并直接显示聊天内容；
- 不显示模型名称、历史按钮、个人中心按钮或调试状态；
- 左右外边距 12 dp，控件高度约 52 dp，圆角约 20 dp，Surface 不透明度为 60%，并使用低强度阴影；
- 聊天内容可以在其下方滚动，但首尾留出安全内边距，不能被遮挡。

## 左侧栏

- 新对话；
- 本机会话历史；
- 当前模型只读信息；
- 个人中心与退出登录入口；
- 后续设置、搜索和文件能力继续放在侧栏，不增加标题栏按钮。

打开历史会话或新建会话后自动关闭侧栏。

## 消息区

- Assistant 消息使用无外层气泡的开放正文样式；
- 用户消息使用右对齐的浅色圆角气泡；
- 等待首个回复片段时，只在 Assistant 消息位置显示一次“正在思考…”，顶部状态区不重复显示；
- 空会话显示 Logo、简短欢迎语，不展示长篇功能说明；
- 消息列表顶部和底部分别为浮动标题栏、输入栏预留空间。

## 浮动输入栏

- 从左到右为：加号、可多行输入框、语音/发送按钮；
- 无文字时显示语音按钮；有文字时自动切换为发送按钮；
- 生成过程中右侧位置切换为停止按钮；
- 输入框最多显示 5 行；Activity 使用 `adjustResize` 分发 IME inset，整个聊天视口消费一次 `imePadding`，使欢迎信息和历史上下文随键盘一起上移，输入栏紧贴 IME 上沿；消息列表在 IME 高度变化时保持当前上下文底部可见；
- 语音按钮调用 Android 系统语音识别，将结果填入输入框，由用户确认后发送；
- 加号是附件与工具的统一入口；第一版尚未接入附件内容时必须给出明确提示，不能静默无响应。

## 验收清单

- [x] 标题栏只保留侧栏、品牌和新会话；
- [x] 标题控件使用彼此独立的浮动 Surface，控件之间透明显示聊天内容；
- [x] 左侧栏可打开本机历史、创建/切换会话并进入个人中心；
- [x] 输入栏包含加号、输入框和语音按钮；
- [x] 输入文字后语音按钮切换为发送；
- [x] 语音识别结果可写入输入框；
- [x] 生成时可停止；
- [x] 回复等待阶段只显示一个“正在思考…”状态；
- [x] 小屏、键盘弹出和长模型名不破坏布局；
- [x] UI 测试、Lint、APK 构建和测试机视觉检查通过。
