# Smart Chat Bar Capability Checklist

Last updated: 2026-07-10

Scope: Windows desktop smart chat bar capabilities across natural-language entry, slash commands, context injection, execution control, runtime modes, multi-agent work, memory/skills/workflows, and cross-channel chat.

Legend: `[x]` complete and verified, `[~]` partial with known gaps, `[ ]` not implemented.

## Current Run Addendum 2026-07-10 Clipboard Text/Image Paste Context

The composer now handles explicit textarea paste events for clipboard images while preserving any accompanying pasted text at the cursor. Pasted image clipboard files are attached as reviewed `selection` context chips with non-filesystem `clipboard:image:*` paths, bounded by `MAX_CLIPBOARD_IMAGE_COUNT` and `MAX_CLIPBOARD_IMAGE_BYTES`; oversized images degrade to metadata-only visible context instead of sending a data URL. The attachment copy makes the boundary explicit: no OCR, vision model, filesystem write, network call, or provider send is performed while preparing clipboard context. `npm run verify:clipboard-context`, `npm run typecheck:web`, and `npm run verify:chatbar-checklist` cover this Clipboard Text/Image Paste Context slice; OS-level clipboard polling, clipboard file-path imports, OCR/vision extraction, image editing, and mobile clipboard handoff remain `[~]`.

## Current Run Addendum 2026-07-10 Clipboard Local Path Paste Mentions

The composer now treats explicit pasted local path text as reviewed inline context references. When a paste event contains absolute Windows/local paths and no clipboard image payload, `normalizePastedLocalPathMentions` rewrites up to `MAX_CLIPBOARD_PATH_MENTIONS` unique paths into visible `@file:"..."` / `@folder:"..."` mentions so the existing inline context assembler can create reviewable chips before send. The paste handler does not poll the OS clipboard, read files or folders, attach hidden file contents, call the network, or send anything to a provider while preparing these mentions. `npm run verify:clipboard-context`, `npm run typecheck:web`, and `npm run verify:chatbar-checklist` cover this Clipboard Local Path Paste Mentions slice; OS-level clipboard monitoring, shell file-drop metadata, existence/type validation, file content previews from paste, and mobile clipboard handoff remain `[~]`.
