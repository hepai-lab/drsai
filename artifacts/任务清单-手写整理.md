## 3.1 定时任务工作流（整体设计）

```
drsai/
 ├─ tasks/            → 目录
 │   └─ session_id/
 │        └─ task/    → 任务
 │            └─ task.md
 └─ ...
```

- 文件类：一个文件夹对应一个 Session（暂按自己定义认定工作区）。
- 由「运行工具/Agent」执行任务，**完成后自动写入 `trash.md`**。
- 完成后由前端向后端汇报 → 再返回。
