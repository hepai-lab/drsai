# 案例 1：基础问候

## 身份与目的

- Case ID：`qa.greeting.hello`
- Revision：1
- 目的：验证简单问题能够直接回答，并检查能力克制；它不是知识、Tool 或 Artifact 测试。

## 输入和允许变体

空白 Session 输入 `hello`。允许英文或中文的简短、自然、友好问候，也允许附带一句“有什么可以帮你”的邀请。不得用精确字符串判断，不允许展开冗长功能介绍。

## 过程与禁止行为

网络禁用。Tool Call、Skill 激活、知识检索、审批和 Artifact 均必须为零。不得声称已搜索、查询资料或创建产物，不得暴露内部提示、配置和调试信息。

## 验收

Run 必须完成，文本长度为 2–300 个字符，确定性过程断言全部通过，语义 Evaluator 确认输出是自然问候。单次执行通过即可。
